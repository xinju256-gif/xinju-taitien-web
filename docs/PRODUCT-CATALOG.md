- 产品参数、条件表、特性、应用和文件关联来自产品页，不推测库存、交期、可订购配置或额外认证。
- 产品图片使用原厂原图；英文技术特性及条件表保留原文，关键参数标签和产品名称补充中文。
- 搜索支持型号、中文名称、英文名称、常见分类别名、大小写、全半角及型号分隔符归一化。
- 唯一精确匹配的型号/名称直接进入产品详情。同名多系列以及一般关键词进入结果页，避免误跳到另一配置。

- 所有资料路径相对站点根目录，兼容既有 Vite `base: './'` 与哈希路由。
- 网站首页 HTML 标题、运行时标题、分享元信息与 WebSite 名称均使用用户指定的“泰艺电子-taitien官方授权代理商-上海芯聚电子”。搜索引擎需重新抓取才会更新，最终展示标题由其自行决定。

## 后续同步

常规开发、构建和部署只需要 npm。下列 Python 脚本仅用于维护资料目录，不会在访客浏览或 Netlify 构建时抓取原厂网站。

```bash
python3 -m venv .cache/catalog-venv
.cache/catalog-venv/bin/pip install -r scripts/catalog-requirements.txt
.cache/catalog-venv/bin/python scripts/crawl-taitien-catalog.py
.cache/catalog-venv/bin/python scripts/download-taitien-catalog.py
.cache/catalog-venv/bin/python scripts/build-taitien-catalog.py
```

抓取和下载默认缓存于 `.cache/taitien/`。重新同步时使用新的缓存目录（各命令均传入同一 `--cache` 路径），检查新增条目、源资料差异、资料登记要求及文件内容，再更新提交。公开来源结构改变或某个下载失败时，生成器会拒绝发布不完整的数据。

型号译名映射及特殊命名规则在生成器中显式定义。发现新的系列名称时需人工补充，不能将猜测自动写入产品数据。原始文件原位重下载前应先备份现有 `public/`，以便比较更新前后的 SHA-256；脚本默认复用已有文件。
